# بوابة الإتاحة — WCAG 2.2 AA (شرط نشر إلزامي)

لا تُنشر أي محاكاة أو صفحة قبل اجتياز هذه القائمة كاملة:

## فحوص آلية (CI)

- [ ] فحص axe على الصفحة والمحاكاة دون أي انتهاك حرج أو جسيم.
- [ ] تباين الألوان محسوب آلياً ≥ 4.5:1 (نص) و≥ 3:1 (مكونات واجهة).
- [ ] كل عنصر تفاعلي له اسم يمكن الوصول إليه (accessible name).

## فحوص يدوية (موثقة في PR)

- [ ] تنقل كامل بلوحة المفاتيح: Tab وShift+Tab وأسهم، دون مصائد تركيز.
- [ ] قارئ شاشة (NVDA أو VoiceOver): الأحداث الجوهرية تُقرأ عبر aria-live بوضوح وبلا إغراق.
- [ ] تكبير 400% دون فقدان محتوى أو وظيفة.
- [ ] `prefers-reduced-motion`: تتوقف الحركات غير الأساسية ويبقى التعلم ممكناً.
- [ ] الاتجاهان rtl وltr: لا انعكاسات مكسورة ولا محاذاة ثابتة.
- [ ] عمى الألوان: كل معلومة لونية لها بديل (شكل/نمط/نص).

## سجل القرار

تُوثَّق نتيجة البوابة في ملف `a11y-report.md` داخل مجلد المحاكاة، مع اسم الفاحص والتاريخ والأدوات.
