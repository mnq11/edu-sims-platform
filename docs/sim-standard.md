# معايير المحاكاة (إلزامية لكل محاكاة جديدة)

## 1. العلم

- النموذج رياضيات صرفة: لا DOM، لا Canvas، لا `Math.random` بلا بذرة موثقة.
- قيم مرجعية لكل ظاهرة (حل تحليلي، ثوابت CODATA، أو مصدر علمي موثق) واختبار يتحقق منها ضمن ±2%.
- تكامل عددي بخطوة ثابتة عبر `SimulationClock`؛ ممنوع التكامل بطول الإطار.
- دقة مزدوجة، والوحدات SI في كل الخصائص العامة، مع توثيق الوحدة في التعليق.

## 2. التعليم

- لكل محاكاة بطاقة تعريف: أهداف تعليمية، مفاهيم، مرحلة دراسية، و3 أسئلة استقصاء على الأقل.
- توجيه ضمني: عناصر التحكم تُظهر العلاقة السببية فوراً، لا قوائم تعليمات.
- تعدد تمثيلات عند الإمكان (حركة + رسم بياني + أرقام).

## 3. الإتاحة (انظر accessibility-gate.md)

- تشغيل كامل بلوحة المفاتيح، وترتيب تنقل منطقي بالاتجاهين.
- منطقة `aria-live` تصف أحداث المحاكاة الجوهرية دون إغراق.
- تباين ≥ 4.5:1 للنصوص، وعدم الاعتماد على اللون وحده، واحترام `prefers-reduced-motion`.

## 4. التقنية والأداء

- حجم الحزمة: ≤ 2MB (2D) و≤ 8MB (3D) مضغوطة.
- بدء تفاعل < 3 ثوانٍ على 3G، و60 إطاراً/ث على جهاز متوسط.
- الحالة قابلة للتسلسل عبر `getState/setState` وتُسترجع من رابط بشكل متماثل.

## 5. اللغة والاتجاه

- كل السلاسل عبر نظام الترجمة، والمصطلحات من المرجع المصطلحي الموحد.
- اختبار العرض rtl وltr إلزامي؛ المنزلقات والمحاور تنقلب منطقياً.
