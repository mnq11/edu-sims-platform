# منصة المحاكاة التعليمية المفتوحة | Open Educational Simulations Platform

منصة محاكاة علمية ورياضية تفاعلية، **مجانية ومفتوحة لجميع المستخدمين دون تسجيل دخول** — عربية أولاً (RTL أصيل)، بإتاحة WCAG 2.2 AA إلزامية، وتعمل دون اتصال كتطبيق ويب تقدمي (PWA).

Free, open, login-free interactive STEM simulations — Arabic-first (native RTL), WCAG 2.2 AA by default, offline-capable PWA.

## المبادئ الحاكمة | Principles

1. **لا حسابات إطلاقاً** — الحالة تُحفظ محلياً وتُشارَك برابط مرمّز، والمزامنة اختيارية برمز مجهول.
2. **العلم أولاً** — النموذج الفيزيائي/الرياضي رياضيات صرفة مختبَرة ضد قيم مرجعية، منفصل تماماً عن العرض.
3. **الإتاحة شرط إطلاق** — لا تُنشر محاكاة قبل اجتياز بوابة WCAG 2.2 AA (لوحة مفاتيح، وصف تفاعلي، تباين، تقليل حركة).
4. **العربية أولاً** — RTL ليس ترجمة لاحقة بل حالة التصميم الافتراضية، مع مرجع مصطلحات علمية موحد.
5. **الأداء حق للجميع** — خطوة زمنية ثابتة، ميزانية حجم صارمة، وتشغيل سلس على أجهزة متواضعة.

## هيكل المستودع | Repository Structure

```
packages/
  core/        @edusims/core       نواة المحاكاة: Property وNumberProperty، ساعة ثابتة، تسلسل حالة، سجل تراجع
  ui/          @edusims/ui         مكونات تحكم Web Components بإتاحة وRTL مدمجين
  catalog/     @edusims/catalog    كتالوج 200 محاكاة جديدة معززة التفاصيل (ضمن خارطة 400)
  assessment/  @edusims/assessment محرك تقييم لحظي وتتبع إتقان لكل مفهوم — محلي بالكامل بلا حسابات
  i18n/        @edusims/i18n       محرك تعريب: العربية مرجع أول، RTL/LTR تلقائي، قواميس قابلة للتسجيل
apps/
  web/         @edusims/web        واجهة المنصة: كتالوج + مشغّل محاكاة بتوجيه هاش + لوحة «اختبر نفسك» + PWA دون اتصال
sims/
  projectile-motion/               الحركة المقذوفة — مرجعية، تحقق من المدى التحليلي ±2٪
  pendulum/                        البندول البسيط — تحقق من زمن الدورة 2π√(L/g) ±2٪
  sorting-visualized/              سباق خوارزميات الفرز — فقاعي/اختياري/إدخالي مع عدّ العمليات
  ohms-law/                        قانون أوم — علاقات جبرية دقيقة V=IR وP=VI
  balancing-equations/             موازنة المعادلات الكيميائية — الحفظ الكتلي لحظياً
  fraction-lab/                    مختبر الكسور — حساب دقيق بالأعداد الصحيحة بلا فاصلة عائمة
  compound-interest/               شجرة الفائدة المركبة — تحقق من الصيغة المغلقة ±0.5٪
  springs-hooke/                   النوابض وقانون هوك — تحقق زمن الدورة ±2٪ وحفظ الطاقة
  density-buoyancy/                الكثافة والطفو — مبدأ أرخميدس: طفو/غوص/حياد جبرياً
  parallelogram-area/              مساحة متوازي الأضلاع — ثابتة القصّ تفاعلياً
  dice-probability/                احتمالات نردين — توزيع نظري مقابل مونت كارلو حتمي
  linear-equations/                الخط المستقيم وميله — y = mx + b بمقاطع وعمودية
docs/                              المعمارية ومعايير المحاكاة وبوابة الإتاحة
```

## الحالة | Status

**146 اختبار وحدة ناجحاً** عبر 16 حزمة، وفحص أنواع صارم نظيف، وبناء Vite مقسّم الشيفرة
لكل محاكاة على حدة (~3.5KB مضغوط للمحاكاة). اثنتا عشرة محاكاة قابلة للّعب داخل التطبيق
بعروض تفاعلية كاملة، ولكل منها لوحة «اختبر نفسك» بتصحيح لحظي وتتبع إتقان —
كل ذلك محلياً على جهاز المتعلم دون حساب.

## البدء | Getting Started

```bash
npm install
npm run dev        # تطوير واجهة المنصة
npm test           # اختبارات الوحدات (vitest)
npm run typecheck  # فحص الأنواع الصارم
npm run build      # بناء كل الحزم
```
